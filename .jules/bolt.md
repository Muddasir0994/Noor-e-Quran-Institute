## 2024-05-24 - Async Database Writes Prevent Event Loop Blocking
**Learning:** The application uses a custom in-memory singleton database (`DataStore`) that persists to a JSON file. Previously, it used the synchronous `fs.writeFileSync` for every data mutation. In a Node.js Express environment, synchronous I/O operations block the main event loop, causing all concurrent requests to stall until the disk write completes, leading to severe performance degradation under load.
**Action:** Always prefer asynchronous file operations (`fs.promises.writeFile`) in singletons or backend routes. When replacing synchronous file writes with async ones in singletons, implement a concurrency queue or lock (e.g., `isWriting`, `pendingWrite`) to prevent overlapping writes from corrupting the file or causing race conditions where data is lost.
