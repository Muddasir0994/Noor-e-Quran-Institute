## 2023-10-27 - Async DataStore and Graceful Shutdown Optimization
**Learning:** Optimizing synchronous file I/O operations (like `fs.writeFileSync`) in high-concurrency Node.js Singletons requires a stateful locking mechanism to queue pending requests efficiently and prevent data loss. Additionally, robust graceful shutdown logic combining `server.closeAllConnections()`, a pending flush mechanism, and a hard timeout is essential for preventing hanging Node.js processes on hosting platforms like Render.
**Action:** Use asynchronous implementations tied with simple boolean state flags (`isWriting`, `pendingWrite`) to create safe queues for background operations without relying on complex external dependencies. Always implement a reliable exit fallback `setTimeout` inside graceful shutdown handlers to protect against hung cleanups.
