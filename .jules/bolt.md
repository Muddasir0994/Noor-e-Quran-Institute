## 2025-03-03 - DataStore Synchronous Write Optimization
**Learning:** The custom `DataStore` singleton was using `fs.writeFileSync` in `saveDatabase`, which blocked the Node.js event loop during high concurrent write operations. This caused subsequent requests to hang or queue up inefficiently, bottlenecking overall backend performance.
**Action:** When implementing custom JSON-based data stores or caching layers, always use asynchronous file writes (`fs.promises.writeFile`). Since singletons can suffer from overlapping async writes causing data loss, implement a concurrency queue lock (like a `while(this.pendingData)` loop) to aggregate rapid saves and ensure the file is written serially without blocking the event loop. Always pair this with a graceful shutdown hook that flushes pending writes to disk before exit.
