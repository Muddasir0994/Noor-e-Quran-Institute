## 2025-02-27 - Async File Writes and Graceful Shutdown
**Learning:** Using synchronous `fs.writeFileSync` in singleton data stores (like `DataStore`) blocks the Node.js event loop on every state mutation, destroying concurrency. However, simply switching to async `fs.promises.writeFile` can cause data loss from overlapping writes or incomplete saves during server shutdown.
**Action:** Implement an async write queue using a `while(this.pendingData)` loop to guarantee sequential, non-blocking disk writes. During graceful shutdown (`SIGTERM`/`SIGINT`), reject new connections via `server.closeAllConnections()` and `server.close()`, and await a `DataStore.flush()` method (which uses a `while (this.writePromise)` loop) to ensure all pending saves are durably written to disk before the process exits, using a fallback timeout to prevent hanging.
