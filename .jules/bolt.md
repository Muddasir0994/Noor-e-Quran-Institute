## 2026-09-27 - [Fix Event Loop Blocking File Writes in DataStore]
**Learning:** The `DataStore` singleton was performing frequent disk writes via the blocking synchronous `fs.writeFileSync()` on the main thread, causing event loop starvation under high traffic. When optimizing this to an asynchronous operation (`fs.promises.writeFile`), naively triggering promises for every write risks race conditions, missing data, and out-of-order execution because of overlapping disk writes.
**Action:** Implemented a concurrency queue loop with a lock (`while (this.pendingData)`). This approach ensures only one asynchronous disk write happens at a time. Assigning the latest payload unconditionally (`this.pendingData = dataToSave || this.data`) ensures rapid concurrent operations collapse into the latest queue state. Also added a `flush()` method coupled with a server graceful shutdown timeout fallback so pending I/O isn't lost on termination.
