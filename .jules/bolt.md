## 2023-10-27 - Synchronous File Writes in Singleton DataStore
**Learning:** The custom `DataStore` singleton (`server/dataStore.ts`) was using a blocking synchronous `fs.writeFileSync` on every database update. Under heavy concurrent load (like the 1000 requests in `test_perf_concurrent.cjs`), this blocked the single Node.js event loop thread, degrading server performance significantly and risking dropped connections.
**Action:** When implementing or encountering singletons that manage file-based storage, replace synchronous blocking writes with an asynchronous concurrency queue (e.g., using `while (this.pendingData)` and `fs.promises.writeFile`). Unconditionally assign the latest data to the pending cache (`this.pendingData = dataToSave || this.data`) so that rapid concurrent saves always pick up the most recent state. Additionally, pair this with a `flush()` method awaited during a `server.close()` graceful shutdown to guarantee data persistence.
