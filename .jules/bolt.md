## 2024-03-01 - Asynchronous Persistence Loop for Synchronous Write Optimization
**Learning:** In singleton configurations like `DataStore` and `seoCache` across this application's backend architecture, synchronously writing heavy JSON blobs to disk on every data mutation via `fs.writeFileSync` creates severe main-thread blocking and introduces extreme latency during concurrent requests (e.g., benchmark scripts or API spikes).
**Action:** When implementing or optimizing disk persistence for server state, use an async lock queue (`while (pendingData)`) wrapped around `fs.promises.writeFile`. During shutdown, implement `server.closeAllConnections()` followed by `server.close()` and ensure a `flush()` mechanism dynamically awaits the running promises (`while (writePromise)`) with a timeout fallback, preventing silent file truncation or process hanging.
