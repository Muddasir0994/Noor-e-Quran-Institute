## 2023-10-27 - Memoize Derived Array State to Avoid O(N*M) Render Blocking
**Learning:** In highly dynamic components like `TeacherPortal` that manage multiple tabs and real-time state updates, redundantly calling mapping functions (`getAssignedStudentEmails`) and filtering large directory arrays inside the render loops for different sub-sections blocks the main thread unnecessarily. This becomes particularly problematic when computing derived state like "My Students", "Roster", and "Messages" synchronously.
**Action:** Extract and centralize the calculation of computationally expensive derived arrays (such as filtering directories based on user relationships) at the top of the component using `useMemo()`. Reuse these memoized lists across all relevant UI sections rather than computing them independently on the fly.
