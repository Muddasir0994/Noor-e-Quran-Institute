## 2024-03-22 - Optimize synchronous fs file write bottlenecks in singleton
**Learning:** Optimizing synchronous file writes (`fs.writeFileSync`) to asynchronous writes (`fs.promises.writeFile`) in singletons like `DataStore` can significantly improve performance under load, but it risks data loss if concurrent rapid saves overlap or if the server crashes before pending writes finish.
**Action:** Used an asynchronous concurrent save lock in `saveDatabase` to batch rapid file writes via an async queue/loop (`while (this.pendingData)` loop in an awaited `flush` mechanism) to prevent overlapping data corruption. Added safe process exit listeners (`SIGTERM`/`SIGINT`) calling `await dataStore.flush()` with `server.close()` to ensure all queued saves are successfully written to disk during graceful shutdown.
