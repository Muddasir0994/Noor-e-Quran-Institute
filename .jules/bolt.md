## 2024-10-12 - Replacing synchronous file writes with an async concurrency queue
**Learning:** Optimizing synchronous file writes (`fs.writeFileSync`) to asynchronous writes (`fs.promises.writeFile`) in singletons like `DataStore` can lead to data loss from overlapping writes or incomplete saves on exit. Using a simple queue loop (`while (this.pendingData)`) guarantees that rapid concurrent saves are executed sequentially and the latest data is always written. To ensure all data is written during graceful shutdown, implementing a `flush()` method using `while (this.writePromise)` is necessary to await the queue of chained asynchronous promises dynamically added during flush.
**Action:** When implementing async file writes in singletons, avoid simple fire-and-forget `fs.promises.writeFile`. Always use a concurrency lock or loop to queue writes. Also, provide a `flush()` method and hook it into process exit events (`SIGINT`/`SIGTERM`) to await any pending writes.
