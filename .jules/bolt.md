## 2024-10-16 - Memoization of Derived Arrays in Render Path
**Learning:** This codebase contains several top-level React components (like `CoursesPage`, `BlogListPage`, `ClassroomStudio`) that handle their own list filtering dynamically based on local state (like search queries and active categories). By default, computing derived arrays like `.filter()` synchronously in the component body triggers a re-evaluation on every re-render (e.g., as the user types a search query), causing potential performance bottlenecks as the lists grow larger.
**Action:** When adding or modifying list filtering logic in React components, ALWAYS wrap the derived array calculations in `React.useMemo` and provide the correct dependency arrays to prevent expensive, synchronous O(n) re-evaluations on every render.
