## 2026-09-23 - Prevent Path Traversal in Image Route
**Vulnerability:** The Express route `/images/:file` passed `req.params.file` directly into `path.join` to locate image files on disk without any validation. An attacker could provide a payload with URL encoded malicious characters like `..%2f` to traverse directories on the server and potentially access sensitive files outside the intended public images directory.
**Learning:** Even though Express router captures segments without slashes, URL-encoded path segments decode into `req.params`, so they bypass segment boundaries after matching. Direct use of user input in filesystem operations (`path.join` and `fs.existsSync`) without sanitizing is a critical security risk.
**Prevention:** Always explicitly validate and sanitize dynamic route parameters used in file path resolution by rejecting input that contains traversal sequences such as `..`, `/`, or `\`. Ensure input matches a strict expected pattern before processing.
