## 2024-05-24 - Cross-Site Scripting (XSS) in React via innerHTML and dangerouslySetInnerHTML
**Vulnerability:** The application was vulnerable to DOM-based XSS by assigning untrusted HTML to `tmp.innerHTML` for text extraction, and vulnerable to Reflected/Stored XSS by directly rendering user-generated HTML in `dangerouslySetInnerHTML` in the admin preview without sanitization.
**Learning:** React's built-in protections are bypassed when using `dangerouslySetInnerHTML` or raw DOM assignments. Additionally, when extracting text from HTML, `innerHTML` can execute malicious scripts (e.g. via `<img>` onerror handlers).
**Prevention:** Always use `DOMPurify.sanitize()` before passing content to `dangerouslySetInnerHTML`. Use `new DOMParser().parseFromString(html, 'text/html').body.textContent` to safely extract text from HTML strings without DOM execution. When providing HTML fallback strings to `DOMPurify.sanitize()`, use the standard HTML `class` attribute instead of React's `className` prop.
